# Aurum Ghana

Luxury Ghanaian jewelry e-commerce platform. Production-grade frontend with HTML5, CSS3, and vanilla JavaScript.

## Quick Start

```bash
# Just open index.html in a browser
# Or use a simple HTTP server:
python -m http.server 8000
# Then visit http://localhost:8000
```

## Structure
- `index.html` - Homepage
- `category.html` - Product listing
- `product.html` - Product detail
- `cart.html`, `checkout.html` - Purchase flow
- `login.html`, `register.html`, `forgot-password.html` - Auth
- `account.html`, `order-history.html` - User area
- `admin.html` + sub-pages - Admin panel
- `styles.css` - All styles (~2000 lines)
- `api.js`, `security.js`, `cart.js`, `products.js`, `auth.js`, `checkout.js`, `admin.js`, `scripts.js` - JavaScript modules

## Features
- Responsive (mobile-first)
- Accessible (ARIA, keyboard nav, skip-links)
- Security hardened (CSP, input sanitization, XSS protection)
- 40 product catalog
- Paystack payment integration ready
- Local-first cart (works offline)
- PWA-ready (manifest.json)
- SEO-friendly (sitemap, robots, semantic HTML)

## Pages (19 total)
- Public: index, category, product, cart, checkout, 404
- Auth: login, register, forgot-password, reset-password, verify-email, mfa
- User: account, order-history
- Admin: admin, admin-products, admin-orders, admin-users, admin-analytics, admin-audit-logs
